# pure-java-rpg-lesson

**Javaの基礎学習を終えた人**が、次の一歩として受ける**入門講座**（1本15分 × 全30回）の教材リポジトリです。
Java の**標準クラスライブラリだけ**で、RPGを1本作りきります。

> **本当の主題は「RPGの作り方」ではありません。**
> **基礎で習ったオブジェクト指向が、実際の場面でどう効いてくるのかを体で分かること**です。
> RPGは、そのいちばん分かりやすい題材として使っています。

## この講座がやらないこと

| やらないこと | 理由 |
| --- | --- |
| **Javaの文法を教えない** | 受講者は習得済み。継承・インターフェースの「定義」は説明しません |
| **ゲームエンジンを作らない** | 使い回せる汎用の仕組みは作らず、**1本のゲームを作りきる**ことに集中します |
| **本格的な難易度にしない** | 本格版は次シリーズ「2D RPG ゲームエンジン編」で扱います |

```
Java 基礎（他の講座で習得済み）
        ↓
★ この講座：RPGを1本作りながら、オブジェクト指向の使いどころを知る
        ↓
   次シリーズ：2D RPG ゲームエンジン編
```

## 教え方の中心：先に困らせてから、道具を出す

オブジェクト指向は、**なぜ必要かを体験しないと身につきません。**
「継承とは〜です」と説明しても「へえ」で終わります。
**同じコードを2回書いてうんざりしてから**継承を使えば、二度と忘れません。

この講座には、その山場が **5回** あります。

| 回 | 何に困るか | どの道具で解決するか |
| --- | --- | --- |
| **第7回** | `Player` をコピペして `Npc` を作り、30行が重複する | **継承**（`Entity`） |
| **第17回** | `switch` の枝が増え、同じ分岐が2か所にできる | **抽象クラス**（`Scene`） |
| **第24回** | 敵の行動が `if` の連なりになる | **インターフェース**（`MonsterAction`） |
| **第26回** | アイテムの種類ごとに `if` が増える | **抽象クラス**（`Item`）※24回との違いを自分で判断させる |
| **第28回** | セーブしたい状態がどこにあるか探す | **カプセル化の効き目**（もう集まっている） |

そして、**効き目は感想ではなく事実で見せます。**

- 第7回：`Entity` を1行直すと、`Player` と `Npc` が同時に直る
- 第19回：戦闘画面を足しても、`git diff GamePanel.java` が**ゼロ**
- 第28回：状態が2か所に集まっているので、セーブが**60行**で書ける

## この講座で答える悩み

| 悩み | 答え方 |
| --- | --- |
| 継承をいつ使うのか実感がない | 継承がないと困る状況を作ってから使う（第7回） |
| インターフェースをいつ使うのか実感がない | 同じく、困ってから使う（第24回） |
| **抽象クラスとインターフェースの違いが曖昧** | 両方を実際に使い、選んだ理由を毎回言葉にする（第17・24・26回） |
| `private` にする意味が分からない | `public` にして壊れる例を見せる（第6回） |
| クラスをどう分ければいいか分からない | 分け方の**判断基準**を、毎回1つ言葉にして残す |

### 持ち帰ってほしい1文

> **状態を配りたいなら抽象クラス。約束だけなら インターフェース。**

## 完成する物

そうげん・まち・どうくつを歩き、NPCと会話し、敵と戦い、レベルを上げ、
道具を買って装備し、セーブして続きから遊べる——**1本のRPG**です。

中身の量（モンスター・アイテム・成長表・会話）は**すべて外部ファイルの行数で決まる**ので、
講座が終わったあと、受講者は**コードを1行も書かずに**増やせます。

## 進めかた（制作側の手順）

1. `docs/02_RULES.md` のルール0とルール1を読み返す
2. **「今日のオブジェクト指向」を先に決めてから**、コードを決める
3. 台本を書き、ルール7のチェックリスト15項目で確認する
4. その回の終わりに `git tag ep01` のようにタグを付ける
   （書き直しの回は `ep17-before` と `ep17` の2つ）
