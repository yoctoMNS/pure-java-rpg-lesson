# pure-java-rpg-lesson

Java の**標準クラスライブラリだけ**で RPG を作る、
プログラミング**未経験者むけの入門講座**（1本15分 × 全30回）の教材リポジトリです。

> **これは入門講座です。** 作るのは**学習用の見本**であり、そのまま売れるゲームではありません。
> かわりに、**RPGに必要な部品を1つ残らず自分の手で作ります。**
> どの部品を作るかは、初代ドラゴンクエストにあった機能を「そろえるべき一覧」として使って決めました。

- 使う道具: **JDK 25** / **Eclipse**
- 外部ライブラリ: **一切使いません**（追加のダウンロードなし、jar の追加なし）
- 素材（絵・音・フォント）: **商用利用OK・再配布OK** のものだけを使います

## この講座で作るもの

30回を終えると、次のことができるゲームエンジンが手元に残ります。

1. マス目のマップを歩き回れる（そうげん・まち・どうくつ、画面のスクロールつき）
2. 話しかけると会話ウィンドウが出る（ひらがな・カタカナ・英数字）
3. 歩いていると敵が出て、コマンドを選んで戦える（ターン制・1人 vs 1体）
4. 勝つと経験値とゴールドが手に入り、レベルが上がる
5. 道具と装備が使える、店と宿屋がある
6. セーブとロードができる（今どきのファイル保存方式）
7. BGM と効果音が鳴る
8. タイトル画面から最後まで、ひととおり遊べる

しかも、**中身の量はすべて外部ファイルの行数で決まる**ように作ります。
講座が終わったあと、受講者は**コードを1行も書かずに**モンスターやアイテムを増やせます。

### この講座の3つの特徴

| | 中身 |
| --- | --- |
| **絵より先に、しくみ** | 第3〜7回は絵を出さず、黒い画面でRPGの中身を作ります。**開始105分で遊べる物が完成**します。そこで作った `Hero`・`Monster`・`DamageCalc` は、第25回の戦闘で**1行も書き直さずに**そのまま使います |
| **なおす回がある** | 第12回は新しい文法を教えません。わざと壊したコードを配り、**エラーの読み方と原因の探し方**だけをやります |
| **毎回、自分で書く時間** | 毎回1分30秒、動画を止めて自分で書く「一時停止チャレンジ」を入れます。30回で合計45分 |

## 進めかた（制作側の手順）

1. `docs/02_RULES.md` のルールに沿って台本を書く
2. コードを書き、その回の終わりに `git tag ep01` のようにタグを付ける
3. 受講者は各回のタグから、その回の完成コードをダウンロードできる
