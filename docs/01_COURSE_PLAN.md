## 第2回 ウィンドウを出して絵を描く

- **ゴール**: 黒い画面に白い四角が描かれ、ドットが大きくくっきり見える
- **今日のゲームづくり**: ★**オフスクリーン描画と論理解像度**（この回のメイン）
  ```
  【用語カード】オフスクリーン描画（下書きに描く）
  ・ひとことで : 画面に直接描かず、いったん「見えない紙」に全部描いてから、まとめて貼る
  ・なぜ必要か : 直接描くと、描いている途中が見えてチラチラする
  ・たとえ     : 黒板に直接書くのではなく、紙に書いてから黒板に貼る
  ```
  ```
  【用語カード】論理解像度
  ・ひとことで : ゲームの中での画面の大きさ。実際のウィンドウの大きさとは別に決める
  ・この講座では: ゲームの中は 256×240、実際のウィンドウは 768×720（3倍）
  ・なぜ必要か : ①ドット絵が大きくくっきり見える ②座標の計算が小さい数字で済む
  ・たとえ     : 小さい原画を描いて、コピー機で3倍に拡大する
  ```
  - **ドット絵を拡大するときの注意**：ふつうに拡大すると、にじんでぼやけます。
    「なめらかにしない」設定（`RenderingHints`）で、くっきりしたドットになります。
    **これはドット絵ゲームでは必ずやる設定**です
- **今日のオブジェクト指向**: **継承（借りる側）**

  - `JFrame` は継承しません。**中身を差しかえたいわけではない**から
  - **第7回では『自分で親を作る側』をやります**と予告
- **前回までにできていること**: プロジェクトの準備
- **さわるファイル**: `Main.java`・`GameWindow.java`・`GamePanel.java`（新規） / **行数のめやす**: 40行

## 第3回 ゲームループ／1秒に60回

- **ゴール**: 四角がひとりでに動き続ける
- **今日のゲームづくり**: ★**ゲームループ**（この回のメイン。ゲーム制作の中心概念）
  ```
  【用語カード】ゲームループ
  ・ひとことで : ゲームが動き続けるための、ぐるぐる回り続けるしくみ
  ・中身       : ①入力を見る ②世界を動かす（update） ③画面を描く（draw）
  ・たとえ     : パラパラまんが。1枚描く → 少しずらす → また描く
  ・大事な点   : キャラが止まって見えるときも、このループは回り続けている
  ```
  ```
  【用語カード】FPS（フレーム毎秒）
  ・ひとことで : 1秒間に画面を描きかえる回数
  ・この講座では: 60FPS（1秒に60回）
  ・なぜ60か   : 多くの画面が1秒に60回書きかわるから。それ以上描いても見えない
  ・1回ぶんの時間: 1000ミリ秒 ÷ 60 ＝ 約16ミリ秒
  ```
  - ★**update と draw を分ける理由**（ゲーム制作でいちばん大事な区別の1つ）
    - `update` … **世界の状態を変える**（位置を動かす、HPを減らす）
    - `draw` … **いまの状態を絵にする。状態は変えない**
    - 混ぜると「描くたびに位置が動く」ようになり、原因が追えなくなります
    - **この2つを最後まで混ぜません。** 30回ずっと守るルールです
- **今日のオブジェクト指向**: **インターフェース（使う側）**
  - `ActionListener` は「**時間が来たら、あなたのこのメソッドを呼びます**」という約束
  - 「自分が呼ぶ」のではなく「**呼んでもらう**」——この向きの逆転が典型的な使い方
  - **第24回では、自分がインターフェースを『作る側』になります**と予告
- **前回までにできていること**: 画面に絵が描ける
- **さわるファイル**: `GamePanel.java` / **行数のめやす**: 25行
- **15分の流れ**:
  - 0:00-0:30 ゴール（四角がひとりでに動く）
  - 0:30-1:00 ふりかえり
  - 1:00-3:30 ★**今日のゲームづくり**（用語カード2枚 ＋ update/draw の区別）。
    **パラパラまんがを実物で見せる**
  - 3:30-5:00 **今日のオブジェクト指向**（上記）
  - 5:00-8:00 **写経①**: `implements ActionListener` と `actionPerformed`
  - 8:00-10:00 **写経②**: `Timer timer = new Timer(1000 / 60, this); timer.start();`
  - 10:00-11:00 **写経③**: `update()` と `draw()` に分けて呼ぶ
  - 11:00-12:30 **一時停止チャレンジ**
  - 12:30-13:30 **なぜスレッドを使わないか**：`Timer` は画面を描く流れと同じ場所で動くので安全。
