# 01. 全30回 チュートリアル計画書

1本 **15分** × **30本**（合計 450分 ＝ 7時間30分）

各回は、次の形で書いてあります。

- **ゴール** … その回が終わったときに、何ができているか
- **前回までにできていること** … 前提の確認（順番の矛盾チェック用）
- **きょうの言葉** … その回で**はじめて**出す専門用語
- **さわるファイル** … 新しく作る／書き足すファイル
- **15分の流れ** … 分刻みの中身
- **動かして確かめること** … 受講者が「できた！」と分かるポイント
- **つまずきポイント** … よくある失敗と、その説明
- **先送り** … 説明せずに書かせるもの → 返す回
- **宿題** … その回の発展課題

## 第6回 ゲームループ／1秒間に60回動かす

- **ゴール**: 四角がひとりでに右へ動き続ける（1秒に60回、画面が描きかえられる）
- **前回までにできていること**: 画面に四角が描ける
- **きょうの言葉**:
  - `ループ（くり返し）`… 同じことを何回もやること
  - `while`… 「～のあいだ、ずっとくり返す」命令
  - `ゲームループ`… ゲームが動き続けるための、ぐるぐる回り続けるしくみ
  - `スレッド`… 本編とは別に、同時に動いてくれる「もう1人の作業係」
  - `implements`… 「この約束を守ります」という宣言（`Runnable` ＝「走らせてもらえます」という約束）
  - `FPS`… 1秒間に画面を描きかえる回数。60FPS ＝ 1秒に60回
- **さわるファイル**: `GamePanel.java`
- **15分の流れ**:
  - 0:00-0:30 ゴール（四角がひとりでに動く）
  - 0:30-1:00 ふりかえり
  - 1:00-4:00 用語カード。**パラパラまんが**でゲームループを説明（1枚描く→少しずらす→また描く）
  - 4:00-7:00 **写経①**: `implements Runnable` を足し、`Thread` を作って `start()`
  - 7:00-10:00 **写経②**: `run()` の中に `while` を書き、`update()`（位置を変える）と `repaint()`（描き直す）を呼ぶ
  - 10:00-12:00 **写経③**: `Thread.sleep(16)` を入れて速さをそろえる。16ミリ秒 ≒ 1秒÷60
  - 12:00-13:00 `sleep` を消すとどうなるか実演（速すぎて見えない／パソコンが熱くなる）
  - 13:00-15:00 まとめ ／ 宿題 ／ 次回予告（自分で動かす）
- **動かして確かめること**: 四角が右へ流れていく。`sleep` の数字を大きくすると遅くなる
- **つまずきポイント**: 画面が真っ白のまま → `repaint()` を呼び忘れている
- **先送り**: `try { } catch (InterruptedException e) { }` → **第8回で説明します**と宣言
- **宿題**: 四角がななめに動くようにする／画面の端で止まるようにする（`if` は次回なので、数字の調整だけでも可）
