# 01. 全30回 チュートリアル計画書（第2版）

1本 **15分** × **30本**（合計 450分 ＝ 7時間30分）

> **この講座の位置づけ**
> RPGの作り方を学ぶ**入門講座**です。作るのは**学習用の見本**であり、売り物のゲームではありません。
> 題材として、初代ドラゴンクエストにあった機能をひととおり、**小さく作り直します。**

各回は、次の形で書いてあります。

- **ゴール** … 終わったときに、何ができているか
- **自分で書けるようになること** … 見本を見ないでも書ける状態の目標
- **前回までにできていること** … 前提の確認（順番の矛盾チェック用）
- **きょうの言葉** … その回で**はじめて**出す専門用語
- **さわるファイル** / **書く行数のめやす**
- **15分の流れ** … 分刻みの中身
- **一時停止チャレンジ** … 動画を止めて、自分で書いてもらう課題
- **動かして確かめること** / **つまずきポイント** / **宿題**
