# 03. 用語集

この講座で出てくる専門用語の**公式の説明**です。
**動画では、必ずこの言い方で説明します。**回ごとに言い方を変えてはいけません。

各用語は「① ひとことで（20文字以内）」「② たとえると」「③ 初出の回」の形で書いてあります。

## 「わざと出さない言葉」の一覧

現場では使いますが、**この講座では最後まで出しません**。かわりの言い方を使います。

| 出さない言葉 | この講座での言い方 |
| --- | --- |
| ポリモーフィズム | 同じ仲間として、まとめて扱える |
| カプセル化 | 中身を勝手にさわられないようにする |
| インスタンス | オブジェクト／実物 |
| インスタンス化 | 実物を作る |
| デザインパターン | よくある作り方 |
| リファクタリング | コードの引っ越し・整理 |
| アルゴリズム | やり方・手順 |
| データ構造 | データの並べ方 |
| ステートマシン | いまの様子で、やることを切りかえるしくみ |
| ダブルバッファリング | 下書きの紙に描いてから、まとめて貼る |
| デルタタイム | （**使わない**。60FPS 固定で作る） |
| 再帰 | （**使わない**。そういう作りにしない） |
| ビット演算 | （**使わない**。セーブは今どきの方式なので不要） |
| スレッド・マルチスレッド | （**使わない**。ゲームループは `Timer` で作る） |
| ポリモーフィズム（再掲） | 同じ仲間として、まとめて扱える |
