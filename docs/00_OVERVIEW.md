# 00. 講座の全体像

## 1. この講座の位置づけ（いちばん大事なところ）

> **これは、RPGの作り方を学ぶ「入門講座」です。**
> 作るのは**学習用の見本**であり、そのまま売れるゲームではありません。

このことを、第1回の冒頭ではっきり言います。理由は2つあります。

1. **受講者が安心するから**。「本格的なゲームを作らされる」と思うと、身構えて離れてしまいます
2. **教える側が正しい判断をできるから**。「本格的にしよう」と思うと、説明を飛ばして
   コードを増やしてしまいます。それは入門講座では**まちがい**です

かわりに、こう言います。

> **「RPGに必要な部品を、ぜんぶ自分の手で作ります。1つ1つは小さいですが、
> ぬけている部品はありません。大きくするのは、講座が終わってからあなたがやることです。」**

題材として、**初代ドラゴンクエストにあった機能**をひととおり作ります。
ただし、そのゲームをまねることが目的ではありません。
「RPGとして最低限そろっているべき部品の一覧」として使っているだけです。

## 2. だれのための講座か

- プログラムを**一度も書いたことがない人**
- 数学が苦手でも大丈夫（**中学までの算数・数学**しか使いません）
- 「ゲームを作りたい」という気持ちだけがあればOK

そのため、この講座では次の2つを**同時に**進めます。

1. Java という言葉の使い方（文法）
2. RPGの作り方

文法だけを練習する回は作りません。**ゲームに必要になった、ちょうどそのときに、その文法を教えます。**

## 3. 教え方の3つの柱

### 柱1. 絵より先に、しくみを作る（第3回〜第7回）

最初の5回は、絵を出しません。黒い画面（コンソール）だけで、
**ステータス・ダメージ計算・勝ち負け・くり返し・乱数**を作ります。

- 絵を出す準備には、初心者には重い文法（継承・インターフェース）が必要です。
  それを、`if` も書けないうちに写させるのは教えたことになりません
- コンソールなら、書いた結果がすぐ文字で出ます。**確かめやすさが段ちがい**です
- ここで作る `Hero`・`Monster`・`DamageCalc` は、**第25回の戦闘でそのまま使います**

**第7回の終わりに、コンソールで遊べる戦闘ゲームが完成します。**
開始からわずか105分で「自分が作った物で遊べる」体験ができます。

### 柱2. 動かないときの直し方を、1回まるごと使って教える（第12回）

未経験者がやめてしまう理由のほとんどは、文法が分からないことではなく、
**「動かないのに、どうしたらいいか分からない」**ことです。

第12回は新しい文法を1つも教えません。わざと壊したコードを配り、
エラーの読み方と原因の探し方だけをやります。

### 柱3. 毎回、自分の頭で書く時間を作る（一時停止チャレンジ）

写経だけの講座を見た人は、「見たことはあるが、自分では書けない」状態になります。
そこで**毎回1分30秒、動画を止めて自分で書いてもらう課題**を出します。
30回で合計45分。まとめて1回練習させるより、少しずつのほうが身につきます。

## 4. 使う道具と、その理由

| 道具 | 何を使うか | なぜそれか |
| --- | --- | --- |
| Java の本体 | **JDK 25** | `void main()` という短い書き方が正式に使える。初心者にやさしい |
| 開発ソフト | **Eclipse**（日本語化されたもの） | 無料。日本語の情報が多い。まちがいを赤い線で教えてくれる |
| 追加の部品 | **なし** | 「ダウンロードで失敗して先に進めない」を起こさないため |

### 標準クラスライブラリだけで、どこまでできるか

| やりたいこと | 使うもの（全部 Java に最初から入っています） |
| --- | --- |
| ウィンドウを出す | `javax.swing`（JFrame, JPanel） |
| ゲームループ | `javax.swing.Timer`（**スレッドは使いません**） |
| 絵を描く | `java.awt`（Graphics, BufferedImage） |
| 画像ファイルを読む | `javax.imageio`（ImageIO） |
| キーボード入力 | `java.awt.event`（KeyListener） |
| 文字（フォント） | `java.awt.Font` |
| ファイルの読み書き | `java.nio.file`（Files） |
| セーブデータ | `java.util.Properties` |
| 音 | `javax.sound.sampled`（Clip） |
| 乱数 | `java.util.Random` |

> **なぜスレッドを使わないか**
> ゲームループは `javax.swing.Timer` で作ります。スレッドを使うと、
> 目に見えない物の説明が必要になるうえ、画面の扱いとしても正しくありません。
> `Timer` なら、約束（インターフェース）を1つ守るだけで済みます。

> **音についての大事な注意**
> Javaに最初から入っている音の機能で鳴らせるのは **WAV / AIFF / AU** です。**MP3 は鳴りません。**
> 素材は WAV で用意します（くわしくは `05_ASSETS.md`）。

## 5. 完成する物の仕様（数字で決めておく）

あとで迷わないように、最初に数字を決めます。**この表が全30回の共通の土台です。**

### 画面

| 項目 | 決めた値 |
| --- | --- |
| ゲームの中の画面の大きさ | **256 × 240** ピクセル |
| 実際に出すウィンドウの大きさ | **768 × 720** ピクセル（上の3倍） |
| 1マスの大きさ | **16 × 16** ピクセル |
| 画面に入るマス数 | **16 × 15** マス |
| 1秒間に描く回数 | **60回**（60FPS） |

### 戦闘

| 項目 | 決めた値 |
| --- | --- |
| 見え方 | フロントビュー（敵だけが正面に見える） |
| 人数 | 味方 **1人**（勇者）／ 敵 **1体** |
| コマンド | たたかう／じゅもん／ぼうぎょ／どうぐ／にげる／さくせん の **6つ** |
| 行動順 | すばやさ ＋ 乱数 でその場で決める |
| ダメージ | `(こうげき力 − しゅび力 ÷ 2)` を基本に、**±25%** のゆらぎ。最低でも 1<br>（第3〜27回は装備がないので `ちから − みのまもり ÷ 2`。第28回で装備分が足される） |
| 会心の一撃 | **32回に1回くらい**。相手のしゅび力を無視する |
| 敵の行動 | 敵ごとの「確率の表」から選ぶ |

### 中身の規模（入門講座として、あえて小さくしています）

| 項目 | 決めた値 | 大きくするのは… |
| --- | --- | --- |
| レベル | **1 〜 10** | 受講者が `levels.csv` に行を足すだけ |
| モンスター | **6種類** | `monsters.csv` に行を足すだけ |
| じゅもん | **2つ**（ホイミ・ギラ） | `spells.csv` に行を足すだけ |
| アイテム | **6個** | `items.csv` に行を足すだけ |
| マップ | **3枚**（そうげん・まち・どうくつ） | マップファイルを足すだけ |
| NPC | **4人** | 台本ファイルに行を足すだけ |
| 持ち物 | **8個まで** | 数字を1つ変えるだけ |
| セーブ | **1か所** | ファイル名を分けるだけ |

**この表がこの講座の考え方をよく表しています。**
規模はすべて**外部ファイルの行数**で決まるように作ります。
だから、受講者は講座が終わったあと、**コードを1行も書かずに中身を増やせます。**

### セーブ

| 項目 | 決めた値 |
| --- | --- |
| 方式 | **今どきのファイル保存**（`java.util.Properties`） |
| 保存場所 | ホームフォルダの `.pure-java-rpg/save.properties` |

## 8. 制作の前提

- **1回で新しく書くコードの上限**（回によって変えます。くわしくは `02_RULES.md`）
  - 第1〜7回: **25行** ／ 第8〜17回: **40行** ／ 第18〜30回: **45行**
  - 上限をすべて使うと1,160行ですが、**実際の見積もりは約915行**（`06_ARCHITECTURE.md`）。
    差の245行が、説明と練習に使える余裕です
- **書き直し（引っ越し）の回は、1つもありません。** 作り足していくだけです
- 各回の完成コードは **git のタグ**（`ep01` 〜 `ep30`）で残します

## 9. 気をつけているリスクと、その対策

| リスク | 対策 |
| --- | --- |
| Eclipse が JDK 25 の新しい書き方（`void main()`）に未対応 | 第1回で確認手順を入れる。ダメだった場合の書き方も画面に出す |
| 素材のライセンス違反 | 使えるのは **CC0 と OFL** だけ（`05_ASSETS.md`）。`assets/CREDITS.md` に必ず記録 |
| 文字化け | 第1回で Eclipse の文字コードを **UTF-8** に設定する手順を必ず入れる |
| 15分に収まらない | 上限行数を回ごとに決めた。詰まっている第1・28・30回は、収録前に時間を測る |
| 説明していない書き方が出てしまう | `04_TERM_ORDER.md` の表で、毎回チェックする |
| 受講者が第12回までに離脱する | 第7回で「遊べる物」を完成させ、達成感を先に渡す |
