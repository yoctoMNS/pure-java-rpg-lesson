# 00. 講座の全体像

## 1. だれのための講座か

- プログラムを**一度も書いたことがない人**
- 数学が苦手でも大丈夫（中学までの算数・数学しか使いません）
- 「ゲームを作りたい」という気持ちだけがあればOK

そのため、この講座では次の2つを**同時に**進めます。

1. Java という言葉の使い方（文法）
2. RPG のゲームエンジンの作り方

文法だけを練習する回は作りません。**ゲームに必要になった、ちょうどそのときに、その文法を教えます。**
（例：マップを敷きつめたいから「くり返し」を習う／敵を出したいから「乱数」を習う）

## 2. 使う道具と、その理由

| 道具 | 何を使うか | なぜそれか |
| --- | --- | --- |
| Java の本体 | **JDK 25** | いま新しく、`void main()` という短い書き方が正式に使える。初心者にやさしい |
| 開発ソフト | **Eclipse**（日本語化されたもの） | 無料。日本語の情報が多い。エラーの場所を赤い線で教えてくれる |
| 追加の部品 | **なし** | 「ダウンロードで失敗して先に進めない」を起こさないため。Java に最初から入っている物だけで作る |

### 標準クラスライブラリだけで、どこまでできるか

| やりたいこと | 使うもの（全部 Java に最初から入っています） |
| --- | --- |
| ウィンドウを出す | `javax.swing`（JFrame, JPanel） |
| 絵を描く | `java.awt`（Graphics, BufferedImage） |
| 画像ファイルを読む | `javax.imageio`（ImageIO） |
| キーボード入力 | `java.awt.event`（KeyListener） |
| 文字（フォント） | `java.awt.Font`（ファイルからフォントを読める） |
| ファイルの読み書き | `java.nio.file`（Files） |
| セーブデータ | `java.util.Properties` |
| 音 | `javax.sound.sampled`（Clip） |
| 乱数 | `java.util.Random` |

> **音についての大事な注意**
> Java に最初から入っている音の機能で鳴らせるのは **WAV / AIFF / AU** です。**MP3 は鳴りません。**
> そのため、素材は WAV で用意します（くわしくは `05_ASSETS.md`）。

## 3. 完成するゲームエンジンの仕様（数字で決めておく）

あとで迷わないように、最初に数字を決めておきます。**この表が全30回の共通の土台です。**

### 画面

| 項目 | 決めた値 | メモ |
| --- | --- | --- |
| ゲームの中の画面の大きさ | **256 × 240** ピクセル | ファミコンと同じ大きさ |
| 実際に出すウィンドウの大きさ | **768 × 720** ピクセル | 上の 3倍。ドットが大きく見えて気持ちいい |
| 1マスの大きさ | **16 × 16** ピクセル | 8×8 の小さな絵を 2×2 でならべた分。ドラクエ1と同じ考え方 |
| 画面に入るマス数 | **16 × 15** マス | 256÷16 = 16、240÷16 = 15 |
| 1秒間に描く回数 | **60回**（60FPS） | |
| 色 | 制限なし（見た目はドット絵風） | 当時のような「16色まで」という制限はかけません |

> **「8×8タイル」と「16×16マス」の関係**
> ファミコンは 8×8 ピクセルの小さな絵を並べて画面を作っていました。ドラゴンクエスト1の地面1マスは、
> その小さな絵を **4枚（2×2）** ならべた 16×16 ピクセルです。
> この講座でも**マス＝16×16ピクセル**で作ります。8×8 の話は、当時のしくみを説明するコラムとして扱います。

### 戦闘

| 項目 | 決めた値 |
| --- | --- |
| 見え方 | フロントビュー（自分からは敵だけが見える。ドラクエ1と同じ） |
| 人数 | 味方 **1人**（勇者）／ 敵 **1体** |
| コマンド | たたかう／じゅもん／どうぐ／ぼうぎょ／にげる／さくせん の **6つ** |
| 行動順 | すばやさ ＋ 乱数 でその場で決める |
| ダメージ | `(こうげき力 － しゅび力 ÷ 2)` を基本に、**±25%** のゆらぎ。最低でも 1 |
| 会心の一撃 | **32回に1回くらい**。相手のしゅび力を無視する |
| 敵の行動 | 敵ごとの「確率の表」から選ぶ（たたかう／じゅもん／ぼうぎょ／なにもしない） |

### 育てる

| 項目 | 決めた値 |
| --- | --- |
| ステータス | HP・MP・ちから・みのまもり・すばやさ |
| こうげき力 | ちから ＋ 武器の強さ |
| しゅび力 | みのまもり ＋ 防具の強さ |
| レベル | **1 〜 30** |
| 成長 | レベルごとの数値を書いた**表（CSVファイル）**を読みこむ |
| レベルアップ | 経験値の合計が、表に書かれた数を超えたら上がる |

### セーブ

| 項目 | 決めた値 |
| --- | --- |
| 方式 | **今どきのファイル保存**（`java.util.Properties` を使ったテキストファイル） |
| 保存場所 | ユーザーのホームフォルダの中の `.pure-java-rpg/save1.properties` |
| スロット数 | 3 |
| ふっかつのじゅもん | **作りません。**「昔はこうだった」というコラムで紹介するだけ（第27回） |

## 6. 制作の前提と、決めておいたこと

- **1回で新しく書くコードは 60行まで**。写経についてこられる限界だからです（ルールは `02_RULES.md`）
- **大きな書き直し（リファクタ）はしない**。一度書いたコードは、あとから作り足す形で育てます
- 各回の完成コードは **git のタグ**（`ep01` 〜 `ep30`）で残します
- **1回だけ例外**: 第14回で、それまで散らばっていた主人公の変数を1つのクラスにまとめます。
  ここは「まとめると楽になる」ことを体験してもらう回なので、前もって第13回の最後に予告します

## 7. 気をつけているリスクと、その対策

| リスク | 対策 |
| --- | --- |
| Eclipse のバージョンが JDK 25 の新しい書き方（`void main()`）に未対応 | 第1回で確認する手順を入れる。ダメだった場合の書き方（`public static void main(String[] args)`）も画面に出す |
| 素材のライセンス違反 | 使えるのは **CC0 と OFL** だけ、とルールで決める（`05_ASSETS.md`）。`assets/CREDITS.md` に必ず記録 |
| 文字化け | 第1回で Eclipse の文字コードを **UTF-8** に設定する手順を必ず入れる |
| 15分に収まらない | 各回の写経コードを60行までに制限。収まらない回は分割済み（例：戦闘は6回に分けた） |
| 説明していない書き方が出てしまう | `04_TERM_ORDER.md` の表で、毎回チェックする |
